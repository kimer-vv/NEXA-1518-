NEXA HELP

Transfer Guide

Applications

Review the application, Interested Alliance(s), Transfer Impact, contact info and final Assigned Alliance. Application ID stays with the submission.

Ordinary / Special

These use limited invite capacity. If a category is full, choose an existing applicant to swap out. The displaced applicant returns to Applications / Not Reviewed.

Open Transfer

Tracks a player who plans to try Open Transfer. It is not a guaranteed invite and does not consume an Ordinary/Special slot.

Waiting List

Persists between cycles. Give an Ordinary Invite, give a Special Invite, return the player to Applications, or remove the Waiting List entry.

Recruiting Alliances

Only alliances marked Recruiting appear on the public form. Turning recruiting off removes the alliance from the form without deleting it from NEXA.

Alliance Distribution

Uses Assigned Alliance, not only the applicant’s preference. Copy by Alliance creates a Discord-ready breakdown.

Manual Priority

Staff override for applicants leadership wants reviewed first regardless of estimated score.
