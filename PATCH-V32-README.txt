NEXA PATCH V32 — DYNAMIC NOTES
Built on V31. The layout structure/positions are NOT changed.

NOTES behavior:
- 1–4 notes: one full-width column.
- 5+ notes: automatically balanced into two columns.
- 10 notes => 1–5 left, 6–10 right.
- 8 notes => 1–4 left, 5–8 right.
- 7 notes => 1–4 left, 5–7 right.
- Notes are automatically numbered.
- Existing typed numbers/bullets are cleaned before re-numbering.
- Long notes wrap naturally inside their column.
- Notes start at a readable font size and auto-fit only if the fixed Notes box would overflow.
- Same rendered Notes markup is preserved for live system, Preview, PNG and PDF export.

No Team, Important, Legend, Formation, footer, or sheet geometry changes are included.
