SvS / Ministry Guide

Events

Create configures the opponent, Prep Monday, Castle/Presidency, forms, schedule publication and live status. Edit changes the same event. Delete removes the event and its dependent event data.

Prep Requests

Players submit resources and preferred UTC times. Preferences help staff prioritize; they are not guaranteed appointments.

Move / Swap / Unschedule

Tap an appointment, then a destination. Empty slot = Move. Occupied slot = choose Swap Times or Move & Unschedule. Unscheduling does not delete the player’s Prep Request.

Recent Changes

Every Move, Swap or Unschedule is logged. Copy Change copies only that update. Undo is available for 30 minutes and will not overwrite a newer conflicting change.

Copy Schedule

Copy a day, the full schedule, or filter by alliance for a clean Discord-ready list.

Verified State Access

Verified members can see private schedule/assignments and internal announcements. External users only see public/basic event content and forms.
