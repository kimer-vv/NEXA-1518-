NEXA • PHASE 2A — EVENT OPERATIONS

UPLOAD / REPLACE IN GITHUB:
1. index.html
2. battle-settings.html
3. event-operations.html (new file)

SUPABASE:
Run NEXA-PHASE-2A-EVENT-OPERATIONS.sql once in the Supabase SQL Editor.

WHAT THIS BUILD ADDS:
- New Event Operations module under Transfers in the Admin Control Center.
- Battle Form routed through Event Operations instead of living under SvS.
- Tabs: Forms, Question Library, Arrange & Preview, Responses.
- Question Library grouped automatically by All Events / SvS / TAL / FDT / combinations.
- Event assignment: SvS, TAL, FDT.
- Role assignment: Joiner, Rally, Joiner + Rally, Everyone.
- Answer types: Short Text, Long Text, Number, Dropdown, Single Choice, Multiple Choice, Checkboxes.
- Unlimited answer options.
- Required, Permanent/Reusable, Active/Inactive.
- Edit, Duplicate, Enable/Disable.
- Arrange & Preview with locked Account + Player Info + Availability + Battle Role.
- Drag/drop and Up/Down ordering for Combat Base + custom questions.
- Separate ordering by Event + Role.
- Player Preview.
- Responses tab reserved for Phase 2B.

IMPORTANT:
This is the Phase 2A builder/foundation. It does NOT yet replace the current live SvS submission logic with TAL/FDT submission logic. TAL/FDT profiles can be built and previewed now; connecting them to future live event instances comes after this structure is approved.
