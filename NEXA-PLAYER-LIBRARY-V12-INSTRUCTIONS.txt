NEXA PLAYER LIBRARY V12

1. Upload "nexa-player-library 12.js" to the main/root folder of the GitHub repository.
2. In index.html, replace the previous library script line with:

   <script src="nexa-player-library 12.js?v=14" defer></script>

3. Do not keep a second nexa-player-library script active in index.html.
4. Commit the two changes and wait for Vercel to finish deploying.
5. On iPhone, reload the page. If the old version appears, close the tab and reopen the site.
