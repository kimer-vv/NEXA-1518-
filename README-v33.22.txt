NEXA v33.22 — Transfer Event Management

Apply on top of the current deployment.

Changes:
- "Transfer Events" renamed to "Event Management".
- Event Management is the FIRST Transfer tab.
- Event Management shows ACTIVE cycles only.
- End Event immediately removes the archived cycle from Event Management.
- Archived cycles remain available in History.
- Transfer Roster active view is cleared after End Event.
- Waiting List is NOT cleared and is intentionally preserved for the next Transfer.
- Existing form/open-after-end behavior is not changed by this patch.

No SQL required.
